# Zapomni 📝

**Zapomni** (Slovenian for *"remember"*) is a free, offline notes app for everyone. Take notes, manage projects, set reminders, record voice memos, and attach photos and videos — all stored privately on your device.

No subscriptions. No ads. No data collection. Just a simple, powerful tool that works for everyone.

---

## Features

- 📝 **Notes** — write and organize your thoughts and ideas
- 📅 **Calendar & Reminders** — never forget important dates or tasks
- 📷 **Photos** — attach photos directly to your notes
- 🎥 **Videos** — record or attach videos
- 🎤 **Voice Memos** — record audio notes quickly
- 🌍 **English & Slovenian** — available in both languages
- 📴 **Fully Offline** — works without internet connection
- 🔒 **Private by Design** — all data stays on your device, nothing is sent anywhere

---

## Privacy

Zapomni does not collect, store, or sell any of your data. Everything you create stays on your device only. There are no trackers, no analytics, and no third-party services.

## Open Source

Zapomni is open source. Feel free to explore the code, report issues, or contribute!

If you want to run the project locally:

```bash
# Install dependencies
npm install

# Build the project
npm run build

# Sync with Android
npx cap sync

# Open in Android Studio
npx cap open android
```

You will need your own API keys if you add any services. See `.env.example` for reference.
